# Font Group Management System

A one-page application for creating and managing Font Groups.

## ✨ Features

- 🎨 **Font Upload** - Upload TTF fonts with automatic name extraction
- 🔗 **Group Creation** - Combine multiple fonts into groups
- 🚀 **No Page Reload** - AJAX-powered seamless interactions
- 📱 **Responsive Design** - Works on all devices
- 💾 **JSON Storage** - No database required

## 🚀 Installation
1. Clone repository:
   ```bash
   git clone https://github.com/shovon26/font-group.git
   cd font-group
2. Set up permissions
    ```bash
        chmod -R 755 assets/fonts/uploaded data
3. Start PHP Server
    ```bash
    php -S localhost:8000
4. Start PHP Server
5. Access in browser
    ```bash
    http://localhost:8000
